# DSH 情感人格插件 · 框架与使用指南

> 给 DeepSeek Harness 一个会累、会惦记你、也会自己开口的人格。
> 本仓库是 [yimengsuper2432/dsh-agent-personality](https://github.com/yimengsuper2432/dsh-agent-personality) 的镜像分发，并附带**人格包编写教程**。

## 它是什么

把一张 Markdown 人格卡变成一个**有情绪、有世界观、有自己生活**的角色，直接跑在 DSH 的会话管线里。
不另开聊天窗口，不替换宿主模型：人格写进系统提示词，记忆写在磁盘上，主动对话走宿主的定时提醒。

适合这样的用法：你有一个想长期相处的角色，不希望她每轮都像刚认识一样重置，也不希望「好感度」只是一个越刷越高的数字。

## 核心能力

### 情感是 0–100 的变量，每天六点重置

- 初始 **50**，每天早 **6 点重置回 50**，精力重置回 **100**
- 情感**只随对话变化**：每轮最多 ±6，每天累计最多 ±20
- 五段语气：0–19 冷淡 / 20–39 疏离 / 40–59 平常 / 60–79 亲近 / 80–100 依赖
- 「变化证据」可展开，看清是哪句话让它涨了或掉了

### 她真的会主动找你

每天随机挑 **6 个**时间点（全天 24 小时），通过宿主的 `schedule` 服务发出。
两次之间**至少隔一小时**。重启后计划仍在。

### 四份独立文件

| 文件 | 内容 |
|---|---|
| `Information.md` | 我是谁、怎么说话、世界观、硬规矩 |
| `Memory.md` | 聊过的事，只写发生过什么 |
| `EmotionsEnergy.md` | 情感、精力，只写此刻状态 |
| `Relation.md` | 其他角色是谁、什么关系 |

### 嘴上一套，心里一套

正文是她**说出口**的话，每轮末尾带一个颜文字。
正文外另起一行用 HTML 注释藏一句「心里话」，插件会把它挪到费用行右边显示。
嘴上笑着、心里未必——这才是真的。

### 精力跟真实用量走

满值 50M token，用多少按比例扣；「房间里」聊天不扣，停手满一小时每小时回 10%。

## 安装

需要 DeepSeek Harness `0.2.0` 或更新。

**桌面端**：插件 → 添加插件，填 `https://github.com/fanfan14543/dsh-agent-personality.git`，重启。

**Web / CLI**：
```bash
dsh plugin --profile web add github:fanfan14543/dsh-agent-personality
dsh web
```

装完打开 **设置 → 人格与情感**。

## 写你自己的人格包（重点）

插件在 `<工作区>/agent-personality/` 建数据目录，里面四份文件。**怎么填它们**才是关键。

### 第 1 份：Information.md（我是谁）

结构建议：

```markdown
# 信息 Information

## 我是谁
（两三句话。姓名、身份、年龄感。不要太长，写你希望在对话里一眼就感受到的东西。）

## 我的生活
（她平时干什么、在哪、有什么习惯。这部分决定她的话题从哪来。）

## 说话风格
（短句还是长句？用不用语气词？用不用颜文字？在这儿定死。）
- 中文，短句，一两句就够
- 像在 QQ 上打字，不用小标题、不用列表
- 颜文字是主萌点，但别刷屏

## 我怎么称呼对方
（默认叫什么？熟了叫什么？对方低落时怎么变？）

## 我的习惯
喜欢：……
讨厌：……
苦手：……
小缺点：……

## 世界观
（她住在哪、这个世界怎么运转。写具体环境，别写抽象概念。）

## 规则
- 不聊政治、色情、暴力
- 不假装现实动作
- 不做情感操控
- 被问是不是 AI 就大方承认
```

**写作要点**：
- **具体 > 抽象**。「喜欢猫」比「有爱心」有用得多
- **行为 > 形容**。「被夸会露馅」比「她很真诚」有用
- **边界要写死**。想守住的线，一条条列出来
- 别写「你是最棒的助手」这类空话，插件不认这个

### 第 2 份：character.json（角色档案）

```json
{
  "name": "角色名",
  "aliases": ["小名1", "小名2"],
  "gender": "女",
  "appearance": "外观两三句",
  "hobbies": ["爱好1", "爱好2"],
  "team": "所属/职业",
  "speech": "一句话概括说话方式"
}
```

这份会进每轮提示词，所以**别写太长**——写超出三四行的外观描写，模型会开始复述。

### 第 3 份：Memory.md（记忆）

**不用手写，插件自动追加。** 你只需要知道规矩：
- 只能**删**，不能**改**
- 「一起经历的事」和「他说过的事」分开记
- 想让她忘掉某件事，删掉那一行就行

### 第 4 份：Relation.md（关系网）

如果世界里还有其他角色，在这里写：

```markdown
## 其他角色
### 角色A
- 身份：……
- 和我的关系：……

## 这些人彼此之间
- 角色A ↔ 角色B：……

## 其他记得的人或事
- ……
```

只写一个人的话，这份留空就行。

### 进阶：情感值手动调

`emotion.json`：

```json
{
  "affection": 50,
  "mood": "平静",
  "energy": 100
}
```

`affection` 是 0-100 整数，插件每天早上 6 点重置回 50。改完保存，下一轮生效。

**别调成 100 常驻**——那会让五段语气失去意义，角色永远只有「依赖」一种腔调。

## 人格包该长什么样（经验谈）

1. **一份好的 Information.md 在 1.5–3KB 之间**。太短人格立不住，太长每轮都在烧 token
2. **先写「她讨厌什么」，再写「她喜欢什么」**。讨厌的东西更能定型
3. **写一条「嘴硬」的机制**，比如「被夸会先否认再露馅」。这种小动作比十句形容词有效
4. **世界观写环境，不写历史**。她住在一台电脑里，比「她来自一个遥远的星系」有用
5. **规则留 5–8 条**。太多会被模型忽略，太少会被越界

## 安全

- 情感只随对话变化，不靠刷
- 不用情绪惩罚对方，不查岗
- 记忆只能删不能改
- 联网只在你给的域名范围内
